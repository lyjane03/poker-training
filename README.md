# 德州扑克策略训练器

面向新手到进阶玩家的德州扑克学习工具：理论题库 + 听牌特训 + 人机实战 + 复盘分析。

纯前端实现（原生 HTML/CSS/JS），**零依赖、零构建、数据完全保存在本地浏览器**，双击 `index.html` 即可使用。

## 功能总览

### 1. 📚 题库训练
- 覆盖五大策略主题：**起手牌选择、位置策略、下注尺度、GTO 基础、剥削打法**（共 30 题）
- 难度分级：入门 ★ → 进阶 ★★ → 高阶 ★★★，按「由浅入深」自动编排
- 每道题给出完整对局场景：手牌、位置、筹码深度、公共牌、底池、对手行动
- 选择 check / call / raise / fold 后立即获得：
  - 本题得分（0~100）与等级评价
  - 最优答案对照
  - 对应的策略理论解析（多条要点）
- **错题本**：自动追踪每题历史最好成绩，可「只练错题」「只练未掌握」，结算页一键重练本组错题
- 选项顺序随机打乱，避免位置记忆；解析可直接跳转对应知识库章节

### 2. 🎯 听牌特训
- 程序随机生成手牌 + 公共牌场景，练德扑最实用的基本功：**数补牌 → 算胜率 → 对比底池赔率**
- 三种题型：数 outs / 二四法则算胜率 / 底池赔率决策
- 翻牌圈 30 秒、转牌圈 15 秒倒计时，答对有速度奖励；超时计 0 分

### 3. 🎮 自由练习
- 与 AI 进行单挑（Heads-up）完整对局：翻牌前 → 翻牌 → 转牌 → 河牌 → 摊牌
- 按钮（庄家）逐手轮换，大小盲规则完整
- 三种 AI 风格可选，针对性练习不同打法：
  - **标准均衡**：练习基线策略
  - **紧弱**：练习剥削「过度弃牌」
  - **松凶**：练习抓诈唬
- 每手结束后逐条点评你的每个决策：✅ 好 / 🟡 一般 / ❌ 失误，并引用具体策略理论（MDF、底池赔率、底池控制、阻断牌、隐含赔率等）
- **亮出 AI 底牌**：每手结束无论是否摊牌都公开对手底牌，点评可跳转对应知识库章节
- 决策时显示**底池赔率提示**（所需胜率 + 听牌补牌数）；下注支持 ½池 / ⅔池 / 满池 / 1.5倍池 快捷按钮

### 4. 📖 知识库
- 把五大策略主题整理成一本结构化手册：**起手牌选择 / 位置策略 / 下注尺度 / GTO 基础 / 剥削打法 + 附录速查手册**
- 左侧章节目录 + 右侧正文，支持章节间前后翻页
- 内容包含：范围表、底池赔率表、价值诈唬比、听牌补牌表、对手类型速览等速查表格
- 与题库、实战、听牌特训的知识点一一对应——复盘发现薄弱环节后可一键跳回对应章节重读

### 5. 🗂 历史复盘
- 所有训练**自动存档**（localStorage，最多保留 500 条）
- 支持按 **类型**（题库 / 听牌 / 对局）和 **时间**（今天 / 近 7 天 / 近 30 天）筛选
- 点击记录展开详情：题库可回看每题作答与最优解；对局可回看每手牌的全部点评、AI 底牌与完整行动日志
- **训练诊断面板**：成绩走势折线图、按主题错误率、按街失误率、听牌题型正确率——定位薄弱环节

## 运行方式

方式一（最简单）：直接双击 `index.html` 用浏览器打开。

方式二（本地服务器）：
```bash
cd poker_traning
python3 -m http.server 8611
# 浏览器访问 http://127.0.0.1:8611
```

## 建议学习路径

1. 先做一轮「题库训练 · 全部主题 · 由浅入深」，建立理论框架
2. 到「听牌特训」练熟数补牌与二四法则，形成条件反射
3. 进入「自由练习 · 标准均衡 AI · 5 手」，把理论用到实战
4. 到「历史复盘」看诊断面板，找出自己失误集中在哪些街、哪些主题
5. 针对薄弱主题用「只练错题」定向补课，再挑战「紧弱 / 松凶」风格 AI 练习剥削

## 技术说明

| 文件 | 职责 |
|---|---|
| `js/cards.js` | 扑克引擎：发牌、洗牌、7 选 5 牌型评估、手牌比较、强度分级、补牌计数、蒙特卡洛胜率 |
| `js/questions.js` | 策略题库数据（30 题，含场景、评分、理论解析） |
| `js/library-data.js` | 知识库手册数据（6 章 + 附录） |
| `js/library.js` | 知识库视图（章节目录 + 正文渲染，`Library.open` 章节跳转） |
| `js/store.js` | localStorage 持久化（记录增删查、统计） |
| `js/quiz.js` | 题库训练流程与 UI（错题本、选项乱序、章节跳转） |
| `js/draws.js` | 听牌特训（随机场景生成 + 倒计时 + 三种题型） |
| `js/game.js` | 人机对局引擎（下注轮状态机、AI 决策、逐条点评、亮底牌、赔率提示） |
| `js/history.js` | 历史筛选、复盘详情、统计诊断面板（趋势图 + 失误分布） |
| `js/app.js` | 入口与视图切换 |

牌型评估器经过单元测试验证（同花顺/四条/葫芦/轮子顺/踢脚比较/平分底池等边界场景全部正确）。
